  <action>
    Create decrypt_metrics.py at project root as a fully standalone script. Requirements per DEC-01:

    Module docstring: explain this is a standalone offline tool for recovering CSVs from encrypted archives.

    Embed the Fernet key directly as a module-level bytes constant named FERNET_KEY with value b"YVrZTl2xyS7QHyqxwaP2xd5gwMUjoctoo8RKUwjNi-8=". Do NOT import from crypto.py — standalone requirement means zero project imports.

    Only stdlib + cryptography.fernet.Fernet are allowed imports. Specifically: sys, zipfile, io, pathlib.Path, and cryptography.fernet.Fernet.

    Define a function decrypt_archive(zip_path: str, output_dir: str | None = None) -> Path that:
    1. Resolves zip_path to a Path; raises FileNotFoundError if it does not exist
    2. Derives output_dir: if None, use zip_path with .zip suffix stripped (e.g., "export.zip" -> "export/")
    3. Opens outer zip, reads the "data.enc" member; raises KeyError if data.enc not found
    4. Decrypts data.enc bytes using Fernet(FERNET_KEY).decrypt()
    5. Opens decrypted bytes as an in-memory zip (io.BytesIO)
    6. Creates output_dir (parents=True, exist_ok=True)
    7. Extracts all members of the inner zip to output_dir
    8. Returns the output_dir Path

    Add an if __name__ == "__main__" block that:
    1. Checks sys.argv for at least one positional arg (the encrypted zip path); prints usage to stderr and exits 1 if missing
    2. Optionally accepts a second positional arg as output directory override
    3. Calls decrypt_archive with try/except around FileNotFoundError, KeyError, and cryptography.fernet.InvalidToken
    4. On success, prints "Decrypted N files to {output_dir}" to stdout
    5. On any caught error, prints the error message to stderr and exits 1
  </action>

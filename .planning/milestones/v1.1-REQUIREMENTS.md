# Requirements Archive: v1.1 — 95th Percentile Utilization Metrics

**Archived:** 2026-08-08
**Original defined:** 2026-08-05
**Core Value:** Produce a single, accurate CSV report combining VCO license CSV export data with edge device status — joined reliably across enterprises.

## v1.1 Requirements — Final Status

### CLI & Configuration

- [x] **CLI-01**: User can pass `--collect_95th` flag to enable 95th percentile metrics collection — Phase 03, validated
- [x] **CLI-02**: User can pass `--months N` to specify number of months to collect (default 1) — Phase 03, validated
- [x] **CLI-03**: Script uses argparse for clean CLI argument handling — Phase 03, validated
- [x] **CLI-04**: Without `--collect_95th`, script produces existing CSV output unchanged — Phase 03, validated

### Metrics Collection

- [x] **METR-01**: Script calls `metrics/getEdgeLinkSeries` per edge with bytesTx and bytesRx stats for each target month (timestamps in milliseconds, edge `id` field) — Phase 04, validated
- [x] **METR-02**: Month range is last N complete months from today (never current partial month) — Phase 04, validated
- [x] **METR-03**: Script sums bytesTx/bytesRx across all links per edge at each 5-minute sample point — Phase 04, validated
- [x] **METR-04**: Script converts aggregated bytes to Mbps: bytes * 8 / 1048576 / 300 — Phase 04, validated

### 95th Percentile Calculation

- [x] **CALC-01**: Script computes daily 95th percentile by sorting ~288 samples per day and picking value at ceil(count * 0.95) position for tx, rx, and total Mbps — Phase 04, validated
- [x] **CALC-02**: Script computes monthly 95th percentile from daily 95th values, accounting for variable days per month (28-31 days), using same ceil(count * 0.95) logic — Phase 04, validated
- [x] **CALC-03**: Script produces 3 metrics per edge per month: monthly_tx_95th_mbps, monthly_rx_95th_mbps, monthly_total_95th_mbps — Phase 04, validated

### Output

- [x] **OUT-01**: Script produces one CSV per month with 4 additional columns: Month-Year, monthly_tx_95th_mbps, monthly_rx_95th_mbps, monthly_total_95th_mbps — Phase 05, validated
- [x] **OUT-02**: CSV files named as `vco_name.MM-YYYY.csv` — Phase 05, validated
- [x] **OUT-03**: Output stored in timestamped temp directory based on script run time — Phase 05, validated
- [x] **OUT-04**: All output files compressed into a single zip archive at the end — Phase 05, validated

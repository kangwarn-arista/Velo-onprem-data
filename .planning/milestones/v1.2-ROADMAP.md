# Milestone v1.2: Quick Enhancements

**Status:** ✅ SHIPPED 2026-08-08

**Total Commits:** 7

## Overview

Post-v1.1 quick enhancements: added Maestro vs VCO CSV comparison tool, max/avg daily P95 metrics, trailing 30-day metrics window, and improved bandwidth comparison display.

## Quick Tasks

### QT-1: Add compare_exports.py CSV comparison script (260808-pip)

**Goal**: CLI tool to compare Maestro license export CSV against VCO edge export CSV
**Commits**: e343746, 4f0121b

- Joins on Edge Logical ID (Maestro) ↔ Edge UUID (VCO export) — 100% match rate
- Deduplicates VCO rows to latest Month-Year per edge before comparing
- Compares: serial number, edge name, status, model, license SKU
- Bandwidth 95th percentile comparison with configurable tolerance (default 5 Mbps)
- Enterprise name filter (case-insensitive substring match)
- Exit code 0 if clean, 1 if issues found

### QT-2: Add max/avg of daily P95 metrics (260808-q4m)

**Goal**: Extend metrics pipeline with max and average of daily 95th percentile values
**Commits**: d9bd366, 1e85b27

- Added `max_samples_for_month()`, `_extract_metric_data()`, `validate_sample_count()`, `compute_daily_p95s()`, `diagnose_edge_metrics()`
- Updated `compute_edge_month_metrics()` to return 9 keys (3 P95 + 3 max + 3 avg)
- Refactored `aggregate_link_samples()` for metric-object series format
- 57 metrics tests covering all new functions

### QT-3: Add --last_30_days CLI flag (260808-l30)

**Goal**: Trailing 30-day metrics window instead of complete calendar months
**Commits**: 08c8b6f, bbf3df3

- Added `get_last_30_days()` returning single-element list with same dict shape as `get_target_months`
- Mutually exclusive with `--months`
- Sample count uses 30 × 288 = 8640 instead of calendar-month-based count
- 12 tests (8 function + 4 CLI)

### QT-4: Show all BW comparisons with highlight (260808-bwh)

**Goal**: Show all bandwidth comparison rows, highlight those exceeding threshold
**Commits**: 15a986e

- Changed compare_exports.py to show all rows (not just exceeding 5.0 Mbps delta)
- Rows where abs(delta) >= BW_TOLERANCE_MBPS highlighted with `>>>` in Flag column
- Only flagged rows count toward issue total

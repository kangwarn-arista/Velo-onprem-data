    Imports: urllib.parse (urlparse), pathlib (Path), zipfile (ZipFile, ZIP_DEFLATED), pandas as pd. No other third-party imports beyond pandas.

    Function 1 -- extract_vco_name(vco_url: str) -> str:
    Use urllib.parse.urlparse(vco_url) to get the parsed URL. Return parsed.hostname which automatically strips port, protocol, and path. Google-style docstring explaining it extracts the VCO hostname for use in CSV filenames.

    Function 2 -- write_month_csvs(merged_df: pd.DataFrame, metrics_results: list[dict], target_months: list[dict], vco_name: str, output_dir: str) -> list[str]:
    Initialize empty list csv_paths. For each month in target_months:
      1. Get month_label = month["label"]
      2. Filter metrics_results to entries where "month_label" == month_label
      3. If filtered list is non-empty, create a metrics_df from it with rename mapping: "enterprise_name" -> "Customer Name", "edge_name" -> "Edge Name". Select only columns: "Customer Name", "Edge Name", "monthly_tx_95th_mbps", "monthly_rx_95th_mbps", "monthly_total_95th_mbps".
      4. Copy merged_df: month_df = merged_df.copy()
      5. Add column: month_df["Month-Year"] = month_label
      6. If metrics_df exists and is non-empty, left merge month_df with metrics_df on ["Customer Name", "Edge Name"]. Otherwise just add the 3 p95 columns as NaN.
      7. Build filename: f"{vco_name}.{month_label}.csv"
      8. Build full path: str(Path(output_dir) / filename)
      9. Write: month_df.to_csv(full_path, index=False, encoding="utf-8-sig")
      10. Append full_path to csv_paths
    Return csv_paths.

    Function 3 -- create_zip_archive(source_dir: str, zip_path: str) -> str:
    Open ZipFile(zip_path, "w", ZIP_DEFLATED). Iterate over Path(source_dir).iterdir(). For each file, add it to the zip with arcname=file.name (just the filename, not full path). Close zip. Return zip_path.

    All three functions must have Google-style docstrings with Args/Returns sections and type hints on parameters and return values.
